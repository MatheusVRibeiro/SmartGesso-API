# SmartGesso API — Contexto Hermes (.hermes.md)

> Backend REST multi-tenant (NestJS + Prisma + MySQL) do SaaS SmartGesso — gestão de empresas de gesso/drywall; consumido pelo Admin Web (BFF) e pelo app Mobile.

## Stack Tecnológica

| Camada | Tecnologia |
|--------|-----------|
| Runtime | Node.js ≥ 22 (`engines` no package.json) |
| Framework | NestJS 11 + TypeScript 5.8 (strict) |
| Banco | MySQL 8.4 (Hostinger, externo — sem Docker) via Prisma ORM 6 |
| Testes | Jest 30 + ts-jest + Supertest (`test/*.spec.ts` + `test/e2e/`) |
| Auth | JWT access + refresh rotativo, Passport, Argon2id; contextos separados `platform/*` (admin) e empresa |
| Segurança | Helmet, CORS allowlist fail-closed, @nestjs/throttler, class-validator + DTOs |
| Docs | Swagger/OpenAPI em `/docs` (`SWAGGER_ENABLED`), `npm run openapi:export` |

## Regras Absolutas

- Commits em PT-BR obrigatórios: `<tipo>(<escopo>): <mensagem em português>`
- NUNCA commitar código quebrado (type-check + build + testes antes)
- NUNCA rodar `npm install`/`npm ci` sem autorização explícita (OneDrive trava node_modules)
- NUNCA modificar `node_modules/`, `dist/`, `.env`
- NUNCA comitar `.env`, segredos, arquivos de build
- NUNCA misturar tokens/guards de admin da plataforma (`platform/*`) com usuários das empresas
- Em rotas mobile/empresa, NUNCA confiar em `companyId` do body — usar a empresa autenticada (guards + contexto)
- Valores financeiros sempre `Decimal(15,2)` no Prisma
- Subagents constroem → agente PRINCIPAL revisa/testa/commita (máx 4 paralelos, nunca ocioso)
- Fail fast > silent fallback (config obrigatória, sem fallback hardcoded)
- `npx prisma generate` após QUALQUER mudança no `prisma/schema.prisma` (client stale → TS2339)
- `prisma migrate dev` falha no Hostinger (P3014 shadow database) — usar `npx prisma db push` ou migration manual
- Rotas estáticas ANTES de rotas dinâmicas (`:id`) no mesmo controller NestJS

## Como Rodar

```bash
cp .env.example .env          # DATABASE_URL, secrets JWT, CORS, seed
npm run db:generate           # prisma generate
npm run db:migrate            # prisma migrate dev (Hostinger: db push)
npm run db:seed               # tsx prisma/seed.ts
npm run start:dev             # nest start --watch (porta 3000)
npm run lint                  # eslint {src,test,prisma} --max-warnings=0
npm run typecheck             # tsc --noEmit
npm run test                  # jest --runInBand
npm run test:e2e              # jest --config ./test/jest-e2e.json
npm run build                 # nest build
npm run openapi:export        # exporta openapi.json
```

Swagger: `http://localhost:3000/docs` (com `SWAGGER_ENABLED=true`).
